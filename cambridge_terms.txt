# Cambridge Record — Cambridge terms and caption corrections
#
# One file, two uses:
#   1. Vocabulary for the MediaScribe / Cablecast caption dictionaries
#      (python improve_captions.py --vocabulary prints the list to paste in)
#   2. Corrections that improve_captions.py applies to meeting transcripts
#
# Three kinds of line:
#   wrong|right     FIX — applied automatically. Only for spellings the captioner
#                   gets wrong; the fix should say what was said, spelled right.
#                   Never add words the speaker didn't say (no "Peabody" →
#                   "Peabody School"), and keep titles ("Remember Hudson" was
#                   "Member Hudson" in a roll call, not "Elizabeth Hudson").
#   ?wrong|right    SUGGESTION — probably wrong, but the same words can be right
#                   ("Kayla" is usually "KLo", but Kayla Goodell spoke at public
#                   comment). Listed for a person to check; never applied.
#   term            VOCABULARY — a correct term for the caption dictionaries.
#                   The right-hand side of every fix is vocabulary too.
#
# Matching is case-insensitive and whole-word. Longer entries apply first,
# and a fix never applies where the right form is already there.
# Lines starting with # are comments. Add new entries as you find errors.
